# Specification

## Summary
**Goal:** Update the final report export to use more accurate column naming and include retailer information.

**Planned changes:**
- Replace 'DSE name' column header with 'Salesman Name' in the exported reports
- Add a new 'Retailer Name' column to the exported reports to display retailer information for each payment entry

**User-visible outcome:** Users will see clearer column naming in their exported reports with 'Salesman Name' instead of 'DSE name', and will have access to retailer information through the new 'Retailer Name' column.
