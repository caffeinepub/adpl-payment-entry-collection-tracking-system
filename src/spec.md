# Specification

## Summary
**Goal:** Publish the current draft build of the ADPL Payment Entry & Collection Tracking System to the Live (public) environment without introducing any functional changes.

**Planned changes:**
- Promote/deploy the latest draft build to the Live (public) version.
- Verify the live URL loads successfully and the login screen is reachable.

**User-visible outcome:** Users can access the Live (public) URL and reach the app’s login screen, with the Live version matching the latest draft at the time of publishing.
